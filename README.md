# 🎬 Telegram Video Banner Bot

Telegram-бот на Python (`aiogram 3.x` + `FFmpeg`), який накладає анімований MP4-банер зі звуком поверх головного відео з ефектом **призупинення (паузи/freeze-frame)**.

---

## 📌 Логіка роботи

1. **Таймінг вставки банера:**
   - Якщо відео триває $\ge 60$ секунд $\rightarrow$ банер вставляється на **20-й секунді**.
   - Якщо відео триває $< 60$ секунд $\rightarrow$ банер вставляється рівно **посередині** (`тривалість / 2`).

2. **Ефект паузи та накладання:**
   - Головне відео відтворюється до точки вставки.
   - На моменті вставки головне відео **призупиняється** (кадр завмирає).
   - Поверх замороженого кадру програється **анімований MP4-банер зі своїм звуком**.
   - Після закінчення банера головне відео **продовжує відтворення** зі своїм звуком до кінця.

3. **Оптимізація під безкоштовні хостинги (Free Tier):**
   - Робота напряму через FFmpeg (`preset veryfast`, низьке використання RAM та CPU).
   - Стабільна робота на безкоштовних тарифах з обмеженням **512 МБ RAM** (Render, Koyeb тощо).
   - Автоматичне очищення тимчасових файлів після кожного запиту.

---

## 🚀 Локальний запуск

1. Встановіть `ffmpeg` на свій комп'ютер (якщо ще не встановлено).
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Створіть файл `.env` (скопіюйте з `.env.example`) та вкажіть ваш `BOT_TOKEN`:
   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   BANNER_PATH=banner.mp4
   ADMIN_IDS=ваш_telegram_id
   ```
4. Додайте файл банера `banner.mp4` у корінь папки (або надішліть його боту після запуску з підписом `/setbanner`).
5. Запустіть бота:
   ```bash
   python bot.py
   ```

## ☁️ Інструкція з розгортання на безкоштовних хостингах

### Варіант 1: Render.com (Найпростіший варіант)
1. Завантажте файли проєкту у свій репозиторій на **GitHub**.
2. Зареєструйтесь на [Render.com](https://render.com).
3. Натисніть **New +** $\rightarrow$ **Background Worker** (або **Web Service**).
4. Підключіть ваш GitHub репозиторій.
5. У налаштуваннях:
   - **Environment**: `Docker` (Render автоматично використає `Dockerfile` із встановленим FFmpeg).
   - **Plan**: `Free`.
6. У розділі **Environment Variables** додайте:
   - `BOT_TOKEN` = `ваш_токен_від_BotFather`
   - `ADMIN_IDS` = `ваш_telegram_id`
7. Натисніть **Create Web Service / Worker**. Бот почне працювати 24/7!

---

### Варіант 2: Koyeb.com
1. Зареєструйтесь на [Koyeb.com](https://koyeb.com).
2. Натисніть **Create Service** $\rightarrow$ **GitHub**.
3. Оберіть репозиторій.
4. Koyeb автоматично виявить `Dockerfile`.
5. Додайте змінні середовища `BOT_TOKEN` та `ADMIN_IDS`.
6. Запустіть сервіс (тариф **Eco Free**).
